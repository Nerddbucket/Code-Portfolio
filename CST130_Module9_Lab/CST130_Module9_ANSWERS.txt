PART 2
• After Ctrl+Z: Stopped (state T)
• Ctrl+Z = pause (SIGTSTP); Ctrl+C = interrupt/kill (SIGINT)
• & = run in background, prompt returns immediately
• jobs = list jobs; bg = resume background; fg = bring to foreground

PART 3
• Try SIGTERM first so process can clean up; SIGKILL force-kills and cannot be caught
• kill = SIGTERM (15); kill -9 = SIGKILL (9)
• Ctrl+C = SIGINT (2)

PART 4
• fork creates a child process
• exec replaces the child with the new program
• & returns immediately because the shell does not wait

PART 5
• Initial nice: 10
• After renice: 15
• Higher nice = LESS CPU preference
• nice = start with priority; renice = change running process
